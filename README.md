# Fitness Body Album System

## Overview

The Fitness Body Album System is a Django-based web application designed for managing workout progress, body transformation photos, and fitness achievements. Users can upload, edit, view, and delete fitness albums through a modern responsive interface.

---

## Features

- Upload fitness progress photos
- Create workout albums
- Edit existing albums
- Delete albums
- Responsive fitness-themed design
- Modern glassmorphism user interface
- Django CRUD functionality
- Cloud deployment using Render

---

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- GitHub
- Render

---

## Installation

### Clone Repository

```bash
git clone https://github.com/luigihanopol1/fitness_body_album_system.git
```

### Navigate to Project

```bash
cd fitness_body_album_system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Server

```bash
python manage.py runserver
```
